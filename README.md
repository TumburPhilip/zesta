# ZESTA

A responsive, static-first brand site for the ZESTA sparkling water concept. It uses the supplied photography, with shared product data and layouts for all four flavor pages.

## Run locally

With Node.js installed, run `npm start` from this folder and open [http://localhost:4173](http://localhost:4173). No packages need to be installed. The homepage can also be opened directly as `index.html`.

The store locator and shopping links are placeholders because retailer and checkout information was not included in the brief.
